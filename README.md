# F050 产测方案画册

飞书多维表格「仪表盘插件」，以「画册视图」卡片网格展示 F050 产测方案文档。卡片手动增删，每张卡片绑定一个产测方案链接并显示文档名称，点击跳转查阅。

## 功能

- **画册卡片网格**：白底圆角卡片 + 渐变封面（蓝白主调）+ 文档名称，卡片间距 16px，浅灰页面背景，仿飞书画册视图。
- **手动增删**：点「＋ 添加卡片」填入产测方案链接即可新增；悬停卡片右上角「×」删除。
- **自动抓标题**：填入链接后自动抓取页面 `<title>` 作为卡片名称（直连 → CORS 代理降级），抓取失败退回手填。
- **点击跳转**：单击卡片在新窗口打开产测方案链接，带悬停上浮 + 按压缩放动画。
- **持久化**：卡片列表以 JSON 存于飞书表「产测方案画册草稿」（字段「画册数据」），跨端共享。

- React 18 + Vite

## 构建

```bash
npm install
npm run build   # 产物输出到 dist/
```

## 发布（沿用 F050 流程图插件经验）

1. 代码推送到 GitHub 仓库（新建独立仓库，如 `f050-plan-album-plugin`）。
2. 飞书开发者中心：创建商品 → 插件类型「仪表盘插件」→ 填 GitHub 仓库地址 → 发布范围「本人可见」。
3. 仪表盘「添加组件 → 插件 → 更多 → 添加自定义插件」填服务地址完成添加。
